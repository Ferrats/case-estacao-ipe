# Estação Ipê

Landing page conceitual para uma pousada familiar fictícia em Olímpia-SP. O projeto integra o portfólio da Ferrato Design e explora direção de arte, arquitetura de informação para hospedagem e conversão para reserva direta.

## Stack

- Astro
- HTML semântico
- CSS responsivo
- JavaScript nativo
- Imagens WebP

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Cloudflare Pages

| Configuração | Valor |
|---|---|
| Framework preset | Astro |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Root directory | `/` ou vazio |
| Production branch | `main` |

## Aviso

Este é um projeto conceitual. A Estação Ipê, seus dados, acomodações, serviços e condições comerciais são fictícios. O formulário de disponibilidade é demonstrativo e não envia nem armazena dados.
